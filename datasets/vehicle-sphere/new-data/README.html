Extended scans: Jeep and truck

Embedding explorer · Browse every source view

All 50,400 source views are available as previews: 10 Jeep and 10 truck configurations, each with 360 headings × seven elevations (2,520 images). Simulated observer captures are excluded from this catalog view and retained separately in the local research lab.

1709 freshly computed SAM 3.1 / EG2 image-vector pairs are in this publication. Pending source views can be browsed, but have no PCA point until extraction finishes. No historical vectors are reused for changed source images. The source preview is an unmasked render, separate from the masked encoder input.

Accepted EG2 descriptions are primary labels; source configuration names remain provenance. Source headings follow (270 − source azimuth) modulo 360. Azimuth at 90° elevation is undefined for physical pose scoring.

All four embedding dimensions use the historical fixed PCA. Cosine scores are similarities, not calibrated identity confidence. The extended archive contains no verified independent mesh/session metadata.
